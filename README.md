# YouTube Skidac

Jednostavan alat za Windows koji sa YouTube linka skida
zvuk (MP3) ili video (MP4).

## Kako se koristi

1. Klikni zeleno dugme **Code** gore desno, pa **Download ZIP**
2. Raspakuj ceo folder na Desktop
3. Dupli klik na `Pokreni.bat`

Prvo pokretanje traje par minuta jer program sam skine
`yt-dlp` i `ffmpeg`. Posle toga radi odmah.

Ako Windows prikaze upozorenje "Windows protected your PC",
klikni **More info**, pa **Run anyway**.

## Napomena

Namenjeno licnoj upotrebi - podkasti, predavanja, snimci
i drugi sadrzaj koji smes da preuzmes.

Koristi [yt-dlp](https://github.com/yt-dlp/yt-dlp) i
[ffmpeg](https://ffmpeg.org/).
